# Исследовательские материалы

Здесь допускаются tracked отчёты, сохраняющие свидетельства, сравнение вариантов
и воспроизводимые экспериментальные наблюдения. Каждый отчёт должен указывать
внешние источники и provenance; применимые лицензионные сведения фиксируются
в `../REFERENCES.md`, а отчёт ссылается на них. Отклонённые варианты, ограничения
и отрицательные результаты также могут сохраняться.

Эти материалы **не являются production-контрактами** и сами по себе не разрешают
реализацию. Они служат входом для решений владельца, фиксируемых в
`../METHODS.md`, `../REFERENCES.md` или другом документе владельца области.
Принятие конкретного метода проходит gate из `../METHODS.md`; состояние работ
хранится в `../ROADMAP.md`.

Не помещать сюда секреты, исходные медиа, модели и runtime-данные. Временные
review/audit-отчёты и `.diff` хранятся вне репозитория по `../../AGENTS.md`.
Этот README устанавливает политику, но не является отчётом исследования DQ/grid.
