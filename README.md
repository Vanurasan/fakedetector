# FakeDetector

Прототип инструмента предварительного анализа изображений, аудио- и видеоматериалов на признаки искусственного создания или модификации.

Система формирует риск-оценку и не устанавливает факт подделки окончательно.

## Состояние проекта

FakeDetector находится в активной разработке. Минимальный запускаемый каркас
Этапа 1 реализован и протестирован.

В текущем каркасе доступны:

- установленный CLI `fakedetector`;
- загрузка YAML-конфигурации;
- переопределение настроек переменными окружения;
- валидация конфигурации через Pydantic;
- фабрика приложения FastAPI;
- служебный endpoint `GET /health`;
- безопасный startup pipeline;
- JSONL-журналирование с ротацией по размеру;
- автоматические quality checks и regression tests.

Бизнес-функции анализа достоверности материалов, upload API, анализаторы,
Web UI, база данных и внешние интеграции ещё не реализованы. Проект не заявлен
как готовый к production deployment.

Детальный актуальный статус, план этапов и критерии готовности находятся в:

- `docs/ROADMAP.md`

## Запуск и проверки

Основной запуск:

```text
uv run fakedetector --config config/config.example.yaml
```

Оперативная проверка сервера:

```text
uv run poe server-smoke
```

Полный quality pipeline:

```text
uv run poe check
```
